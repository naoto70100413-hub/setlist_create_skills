# ダンスイベント 入力ファイル整形スキル

## 概要

申込フォームから出力された2つのCSVファイルを結合・整形し、
`create-setlist` スキルが受け付ける5列Excelファイルを生成する。

---

## 入力ファイル構成

### ファイル1: 曲情報CSV
| タイムスタンプ | 受付番号 | 曲名 | アーティスト名 |
|--------------|---------|------|--------------|
| 2024-01-01 10:00:00 | 001 | ダンシングクイーン | ABBA |

### ファイル2: チーム情報CSV
| タイムスタンプ | 受付番号 | チーム名 | 掛け持ち１ | 掛け持ち２ | ... | 希望時間帯 |
|--------------|---------|---------|---------|---------|-----|---------|
| 2024-01-01 10:00:00 | 001 | TEAM_A | TEAM_C | | | 前半 |

- **掛け持ち列**: 「掛け持ち」を含む列名をすべて自動検出して統合する
- 固定列（掛け持ち１〜N）＋オーバーフロー列（複数チームが1セルにまとまっている）の両方に対応
- **タイムスタンプ列**（任意）: フォームの回答が修正・再送信されて同一受付番号の行が複数ある場合、
  タイムスタンプが最も新しい行のみを採用する（各ファイル内で個別に判定）

---

## 実行手順

### Step 1: 入力確認

ユーザーから以下を確認する:
1. **ファイル1のパス**（曲情報CSV）
2. **ファイル2のパス**（チーム情報CSV）
3. **出力ファイルパス**（省略可、デフォルト: `setlist_input_YYYYMMDD.xlsx`）

### Step 2: スクリプト実行

```bash
PYTHONIOENCODING=utf-8 python3 "<SKILL_DIR>/scripts/format_input.py" \
  --songs "<曲情報CSVパス>" \
  --teams "<チーム情報CSVパス>" \
  --output "<出力Excelパス>"
```

列名がデフォルトと異なる場合のオプション:
```bash
  --col-id "申込番号"        # 受付番号列の名前（デフォルト: 受付番号）
  --col-song "曲"           # 曲名列の名前
  --col-artist "アーティスト" # アーティスト名列の名前
  --col-team "チーム"        # チーム名列の名前
  --col-pref "希望"          # 希望時間帯列の名前
  --col-shared-prefix "掛け持ち"  # 掛け持ち列のプレフィックス
  --col-timestamp "送信日時"  # タイムスタンプ列の名前（デフォルト: タイムスタンプ）
```

### Step 3: 結果確認・報告

- 生成したExcelファイルのパスを伝える
- 結合できたチーム数・結合できなかった受付番号（片方のファイルにしかない）を報告する
- 受付番号の重複が検出された場合はその件数を伝える（タイムスタンプが新しい行を自動採用済み）
- 次のステップとして `create-setlist` スキルへの入力を促す

---

## 処理内容

1. **重複排除**: 各ファイル内で受付番号が重複する行がある場合、タイムスタンプ列の値が最も新しい行のみを残す
   - タイムスタンプ列が存在しない、または全行で解析できない場合はファイル内で最後に登場した行を残す
2. **結合**: 受付番号をキーに2ファイルを inner join（両方に存在する行のみ）
3. **掛け持ち統合**: 「掛け持ち」を含むすべての列の非空値をカンマ区切りで1列に統合
   - オーバーフロー列にすでにカンマ区切りで入っている場合もそのまま展開して統合
4. **出力**: 5列の整形済みExcel（create-setlist の入力フォーマット）

---

## 出力フォーマット

| チーム名 | 曲名 | アーティスト名 | 掛け持ちチーム | 希望時間帯 |
|---------|------|--------------|--------------|---------|

- 掛け持ちなし → 空欄
- 複数掛け持ち → カンマ区切り（例: `TEAM_C, TEAM_E`）
