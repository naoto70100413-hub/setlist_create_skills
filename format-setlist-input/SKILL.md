# ダンスイベント 入力ファイル整形スキル

## 概要

申込フォームから出力された2つのCSVファイルを結合・整形し、
`create-setlist` スキルが受け付ける6列Excelファイルを生成する。

---

## 入力ファイル構成

### ファイル1: 曲情報CSV
| タイムスタンプ | 受付番号 | 曲名 | アーティスト名 |
|--------------|---------|------|--------------|
| 2024-01-01 10:00:00 | 001 | ダンシングクイーン | ABBA |

### ファイル2: チーム情報CSV
| タイムスタンプ | 受付番号 | チーム名 | 掛け持ち１ | 掛け持ち２ | ... | 希望時間帯 |
|--------------|---------|---------|---------|---------|-----|---------|
| 2024-01-01 10:00:00 | 001 | TEAM_A | TEAM_C | | | 前半 |

- **掛け持ち列**: 「掛け持ち」を含む列名をすべて自動検出して統合する
- 固定列（掛け持ち１〜N）＋オーバーフロー列（複数チームが1セルにまとまっている）の両方に対応
- **タイムスタンプ列**（任意）: フォームの回答が修正・再送信されて同一受付番号の行が複数ある場合、
  タイムスタンプが最も新しい行のみを採用する（各ファイル内で個別に判定）
- **受付番号の書式ゆれ**: 「01 チーム名」のように余分な文字列が付いている場合、
  先頭の数字部分だけを自動抽出して正規化する
- **チーム名未定の申込**: チーム名が空欄・「未定」「TBD」等の場合、受付番号を付記した
  一意な仮名（例: `未定(No.18)`）に自動的に置き換える（複数チームで名前が衝突するのを防ぐ）

---

## 実行手順

### Step 1: 入力確認

ユーザーから以下を確認する:
1. **ファイル1のパス**（曲情報CSV）
2. **ファイル2のパス**（チーム情報CSV）
3. **出力ファイルパス**（省略可、デフォルト: `setlist_input_YYYYMMDD.xlsx`）

### Step 2: スクリプト実行

```bash
PYTHONIOENCODING=utf-8 python3 "<SKILL_DIR>/scripts/format_input.py" \
  --songs "<曲情報CSVパス>" \
  --teams "<チーム情報CSVパス>" \
  --output "<出力Excelパス>"
```

列名がデフォルトと異なる場合のオプション:
```bash
  --col-id "申込番号"        # 受付番号列の名前（デフォルト: 受付番号）
  --col-song "曲"           # 曲名列の名前
  --col-artist "アーティスト" # アーティスト名列の名前
  --col-team "チーム"        # チーム名列の名前
  --col-pref "希望"          # 希望時間帯列の名前
  --col-shared-prefix "掛け持ち"  # 掛け持ち列のプレフィックス
  --col-timestamp "送信日時"  # タイムスタンプ列の名前（デフォルト: タイムスタンプ）
```

### Step 3: 結果確認・報告

- 生成したExcelファイルのパスを伝える
- 結合できたチーム数・結合できなかった受付番号（片方のファイルにしかない）を報告する
- 受付番号の重複が検出された場合はその件数を伝える（タイムスタンプが新しい行を自動採用済み）
- **重複申込の疑い**（曲名・アーティスト名が完全一致する別受付番号）が検出された場合、
  「重複疑いチェック」シートを確認するようユーザーに伝える。氏名・メールでの照合は
  行っていないため最終判断はユーザーに委ねる（出演者情報フォームを提出済みの方を
  正とするのが一般的）
- 次のステップとして `create-setlist` スキルへの入力を促す

---

## 処理内容

1. **受付番号の正規化**: 先頭の数字部分だけを抽出（書式ゆれ吸収）
2. **重複排除**: 各ファイル内で受付番号が重複する行がある場合、タイムスタンプ列の値が最も新しい行のみを残す
   - タイムスタンプ列が存在しない、または全行で解析できない場合はファイル内で最後に登場した行を残す
3. **結合**: 受付番号をキーに2ファイルを inner join（両方に存在する行のみ）
4. **チーム名未定の解決**: 空欄/「未定」等のチーム名を受付番号付きの一意な仮名に置き換える
5. **掛け持ち統合**: 「掛け持ち」を含むすべての列の非空値をカンマ区切りで1列に統合
   - オーバーフロー列にすでにカンマ区切りで入っている場合もそのまま展開して統合
   - 「チーム名/曲名」「チーム名（備考）」のような形式は前半のチーム名候補を抽出する
   - 分割によってチーム名自体（読点を含む名前等）が壊れないよう、既知のチーム名
     リストと照合して復元を試みる
   - **既知の限界**: 曲名・アーティスト名を手がかりに「チーム名未定」の相手を
     逆引きする（例:「dirtywork（チーム名未定）」→曲がDirty Workのチームを探す）
     ような高度な名寄せは自動化していない。掛け持ち列に解決できない記述が
     残っている場合は、曲名・アーティスト名を手がかりに人手で確認すること
6. **重複申込チェック**: 曲名・アーティスト名が完全一致する行が複数の受付番号に
   またがっていないか検出する（簡易版。氏名・メールでの厳密な照合はしない）
7. **出力**: 6列の整形済みExcel（create-setlist の入力フォーマット）+ 該当時のみ
   「結合エラー」「重複疑いチェック」シート

---

## 出力フォーマット

| 受付番号 | チーム名 | 曲名 | アーティスト名 | 掛け持ちチーム | 希望時間帯 |
|---------|---------|------|--------------|--------------|---------|

- 掛け持ちなし → 空欄
- 複数掛け持ち → カンマ区切り（例: `TEAM_C, TEAM_E`）
